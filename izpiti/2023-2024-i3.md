## Naloga 3 (25 točk)
Napiši funkcijo `drzavno_povprecje`, ki kot argument sprejme *slovar*, kot ga vrača 2. naloga (tj. slovar oblike ```{'starosti': [28, 33, 26, 23, 24, 26],
 'goli': [0, 0, 1, 0, 0, 0],
 'rumeni_kartoni': [0, 0, 1, 1, 2, 0],
 'rdeci_kartoni': [0, 0, 0, 0, 0, 0]}```).

Funkcija naj vrne slovar, kjer se pod naslednjimi ključi nahajajo ustrezne povprečne vrednosti: 

* pod ključem `'povprecna_starost'` naj bo povprečna starost igralcev zaokrožena na dve decimalni mesti natančno (v primeru, da povprečne starosti ne moremo izračunati, naj bo pod tem ključem vrednost `False`),
* pod ključem `'najvec_golov'` naj bo kot vrednost največje število golov, ki jih je zadel posamezen igralec (v primeru, da je seznam z goli prazen, naj bo pod ključem vrednost `0`),
* pod ključem `'kazni'` naj bo terka oblike `(rumeni, rdeci)`, kjer `rumeni`ponazarja seštevek vseh rumenih kartonov, `rdeci` seštevek vseh rdečih kartonov (v primeru, da je katerikoli seznam s kaznimi prazen, naj bo na njegovem mestu v terki vrednost `0`).

Povprečno število golov naj bo zaokroženo na 2 decimalni mesti.

Primer pravilne izvedbe funkcije:

```Python
>>> slovar = drzavni_seznami(seznam, "France")
>>> slovar
{'starosti': [28, 33, 26, 23, 24, 26],
 'goli': [0, 0, 1, 0, 0, 0],
 'rumeni_kartoni': [0, 0, 1, 1, 2, 0],
 'rdeci_kartoni': [0, 0, 0, 0, 0, 0]}
>>> drzavno_povprecje(slovar)
{'povprecna_starost': 26.67, 'najvec_golov': 1, 'kazni': (4, 0)}
```
